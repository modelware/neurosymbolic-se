# NSEE Capstone Roadmap

Modelware · Neurosymbolic Systems Engineering (NSEE)

Build your own capstone through five cumulative project increments. Each project builds on the previous one; review and submission points are relative to module completion.

| Project | Modules | Outcome | Ready for review |
| --- | --- | --- | --- |
| [Project 1: Scope and questions](Module1.md#project-1-module-1-project-scope--problem-statement) | 1 | System boundary, stakeholders, 3–5 engineering questions, difficulty, and source data | After Module 1, before beginning Module 2 |
| [Project 2: Representation and reasoning](Module2.md#project-2-modules-2-3-module-2-component-initial-vocabulary-and-description) | 2–3 | Initial vocabulary and descriptions, bundles, reasoning features, and explained results | After Module 3, before beginning Module 4 |
| [Project 3: Methodology and analysis](Module4.md#project-3-modules-4-5-module-4-component-turn-your-vocabulary-into-a-small-methodology) | 4–5 | Authoring patterns, validation, editors, reusable templates, queries, dashboards, and diagnosed gaps | After Module 5, before beginning Module 6 |
| [Project 4: Grounded AI](Module6.md#project-4-module-6-put-an-agent-to-work-on-your-method) | 6 | Agent comparison, verified model changes, improved guidance, and the evidence from all four experiment rounds | After Module 6, before beginning Module 7 |
| [Project 5: Generation, publishing, and a controlled release](Module7.md#project-5-modules-7-8-module-7-component-generate-publish-and-reuse-your-methodology) | 7–8 | A generator, a reusable package, an independent consumer, and verified release `1.0.0` with a final report | After Module 8 |

For a project spanning two modules, preserve the evidence from each component and submit the cumulative result at its end. Keep the exact repository revisions that support your findings. Module 7 introduces a separate consumer repository; record its version relationship to the methodology repository.

Your final report should trace each Module 1 question to evidence in release `1.0.0`, or explain the diagnosed gap and what would be needed to resolve it. Email each project submission directly to **Dr Maged Elaasar** at [melaasar@modelware.io](mailto:melaasar@modelware.io), following the evidence requirements in the module guides and the [course guide](CourseGuide.md).
